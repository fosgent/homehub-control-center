# Architecture Decision Records

ADR status values: `Proposed`, `Accepted`, `Superseded`, `Rejected`.

Every ADR contains Status, Context, Decision, Alternatives, Consequences, and Security implications. Accepted means the architecture is fixed enough for implementation; it does not mean the feature is implemented.
