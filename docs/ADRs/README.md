# Architecture Decision Records

ADR status values: `Proposed`, `Accepted`, `Superseded`, `Rejected`.

Every ADR contains:
- Status
- Context
- Decision
- Alternatives
- Consequences
- Security implications

A `Proposed` ADR is not treated as an implemented or final architecture decision.
